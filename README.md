# 三角洲行动 ACE 扫盘卡顿优化

《三角洲行动》一进游戏，ACE 会带起两个进程：`SGuard64.exe`（任务管理器里叫 ACE-Guard Client）和 `SGuardSvc64.exe`（ACE-Guard Service）。它们默认跑在所有核心上、优先级是正常，扫盘那一下就是卡顿的来源。

手动处理很烦：两个进程、优先级要改成“低”、相关性要只留一个 CPU，每次开游戏还得重新点一遍，中间弹两次 UAC。

这个脚本帮你做完，装一次就再也不管了。它不会关掉 ACE 的扫描，只是让这两个进程只占一个核心、优先级降到最低，永久解决ACE扫盘卡顿问题。



## 包里就两个文件

| 文件 | 干什么用的 |
| --- | --- |
| `一键安装.cmd` | 双击它就完事 |

## 安装

双击 `一键安装.cmd`，弹出 UAC 点“是”。只在这一步点一次，以后开游戏不会再弹。

它会自动做三件事：把脚本放到 `C:\ProgramData\DeltaForce-ACE-Tuner\`；按你的 CPU 线程数把目标 CPU 设成最后一个（24 线程 → CPU 23）；注册一个后台任务。

## 之后是什么样

不玩游戏的时候，机器上没有任何脚本进程。

你点开始游戏 → ACE 装驱动 → 系统把脚本叫起来 → 它把两个进程设成低优先级、只允许在最后一个 CPU 上跑 → **设完立刻退出**。

WeGame、游戏启动器、桌面图标，用哪种方式开游戏都生效，也不用改快捷方式。

## 确认生效

打开 `C:\ProgramData\DeltaForce-ACE-Tuner\ace-tuner.log`，看到这两行就是成功了：

```
已设置 SGuard64 (PID xxxxx)：相关性=CPU23 优先级=Low
已设置 SGuardSvc64 (PID xxxxx)：相关性=CPU23 优先级=Low
```

也可以任务管理器 → 详细信息 → 搜 `ACE`，右键那两个进程看“设置优先级 / 设置相关性”。

## 卸载

再双击一次 `一键安装.cmd`，它会问你做什么，选 `1`（卸载），UAC 点“是”就清干净了：后台任务、脚本目录都会删掉。

## 几个常见问题

**脚本会一直占 CPU 吗？** 不会，设置完就退出了；等 ACE 进程出现的那段也是内核级等待，基本不占。

**ACE 的进程一开始看不到？** 正常，它比游戏本体晚一两分钟才出来，脚本会一直等，不会漏。

**会不会被封号？** 脚本做的事和你在任务管理器里手动点“设置优先级 / 设置相关性”完全一样，不碰游戏文件、不注入、不读写游戏内存，也不结束任何进程。用不用自己判断。

**想换一个 CPU 编号？** 记事本打开 `C:\ProgramData\DeltaForce-ACE-Tuner\ace-guard-tuner.ps1`，最上面第一行 `[int]$CpuIndex = 23,` 改个数字即可，存盘后下次启动游戏生效。
